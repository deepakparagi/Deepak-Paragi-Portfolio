## 📌 About

This portfolio is more than a static page — it's a **WebGL-powered interactive experience** designed to showcase engineering depth, design sensibility, and real-world projects across AI automation, machine learning, and full-stack web development.

Built from the ground up with performance and aesthetics in mind, every interaction — from the custom loading sequence to the magnetic cursor effects — is intentionally crafted to deliver a premium user experience.

## 🚀 Getting Started

### Prerequisites

- **Node.js** ≥ 18.x
- **npm** ≥ 9.x

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/deepakparagi/Deepak-Paragi-Portfolio.git

# 2. Navigate into the project
cd Deepak-Paragi-Portfolio

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

The app will be available at `http://localhost:5173/Deepak-Paragi-Portfolio/`

## 🌐 Deployment

This project is configured for **automated deployment** to GitHub Pages.

### Automatic (CI/CD)

Every push to the `main` branch triggers the [GitHub Actions workflow](.github/workflows/deploy.yml):

1. **Checkout** → Clones the repository
2. **Install** → Runs `npm ci` with Node.js 20
3. **Build** → Creates the optimized production bundle
4. **Deploy** → Publishes `./dist` to the `gh-pages` branch

### Manual

```bash
# Build and deploy in one command
npm run deploy
```
