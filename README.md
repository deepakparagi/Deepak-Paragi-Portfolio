## ✨ Key Features

- **Immersive 3D Experiences:** Powered by `Three.js` and `React Three Fiber` for interactive WebGL elements.
- **Cinematic Motion:** Smooth animations and page transitions using `Framer Motion`.
- **Fluid Scrolling:** Implementation of `Lenis` for premium smooth-scrolling mechanics.
- **Responsive Architecture:** Fully optimized for mobile, tablet, and desktop devices.
- **Dynamic Content:** Showcases projects involving AI automation, machine learning, and full-stack web applications.

## 🛠️ Technology Stack

- **Core:** React 19, Vite
- **Styling:** Tailwind CSS, PostCSS
- **Animation & 3D:** Framer Motion, GSAP, Three.js, React Three Fiber, Lenis
- **Icons:** Lucide React
- **Deployment:** GitHub Pages (Automated via GitHub Actions)

## 📦 Local Installation

To run this project locally on your machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/deepakparagi/Deepak-Paragi-Portfolio.git
   cd Deepak-Paragi-Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

## 📜 Available Scripts

| Script | Description |
| :--- | :--- |
| `npm run dev` | Starts the Vite development server on `localhost` |
| `npm run build` | Builds the application for production inside the `dist` folder |
| `npm run preview` | Previews the production build locally |
| `npm run lint` | Runs ESLint to check for code quality and syntax issues |
| `npm run deploy` | Deploys the `dist` folder directly to GitHub Pages |
